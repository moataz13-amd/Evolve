# مواعيد الشحن والتوصيل

صفحة المنتج تعرض تاريخ تأكيد الطلب، والشحن المتوقع، ونطاق الوصول المتوقع.
المدد المتفق عليها: التجهيز يومان، والتوصيل خلال ١–٥ أيام بعد الشحن. الحساب افتراضيًا بالأيام العادية، حسب توقيت القاهرة.
المواعيد تقديرية وليست ضمانًا، وقد تختلف حسب العنوان وشركة الشحن والعطلات الرسمية.

## إعدادات الأدمن

شغّل محتوى الملف `backend/supabase/migrations/202610080001_delivery_estimates.sql` مرة واحدة من Supabase → SQL Editor → New query → Run.
أو بعد ضبط معرّف المشروع وربطه، استخدم `npm run db:push`.

بعد ذلك افتح Admin → Settings → Edit بصلاحية super_admin:

- Show product delivery estimates: إظهار المواعيد أو إيقافها.
- Preparation: الحد الأدنى والأقصى لأيام التجهيز.
- Delivery: الحد الأدنى والأقصى لأيام التوصيل **بعد الشحن**.
- Exclude Friday and Saturday: استبعاد الجمعة والسبت من المرحلتين.
- Delivery time zone: المنطقة الزمنية للمتجر، افتراضيًا Africa/Cairo.

بدون ترحيل قاعدة البيانات، يستخدم الموقع المدد المتفق عليها. بعد الترحيل، يعتمد على القيم المحفوظة في الإعدادات. لا يعرض مواعيد إذا كانت الإعدادات غير صالحة أو الاختيار غير متوفر.
